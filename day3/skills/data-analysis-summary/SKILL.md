# Data Analysis Summary

Use this skill when the user provides analysis results, metrics, or statistical findings and asks for a concise summary.

## Procedure

1. State the main result in one sentence.
2. List exactly three important findings.
3. Explain one practical implication.
4. Mention any important limitation or uncertainty.
5. Finish with one recommended next action.

## Rules

- Keep the response under 200 words.
- Do not invent statistics.
- Preserve numerical values exactly as provided.
- Distinguish observations from interpretations.
- Avoid unnecessary technical jargon.
